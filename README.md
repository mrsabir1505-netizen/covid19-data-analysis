# COVID-19 Global Data Analysis

## Objective
Exploratory Data Analysis (EDA) of global COVID-19 data to understand trends in confirmed cases, deaths, and recoveries, and to compare impact across countries and continents.

## Dataset
Source: Kaggle - COVID-19 Dataset (imdevskp)
Files used: day_wise.csv, country_wise_latest.csv, worldometer_data.csv

## Key Insights
1. Global recovery rate reached approximately 50%, while death rate remained around 3-4%, indicating relatively low overall fatality despite high case count.
2. The US recorded the highest confirmed cases, followed by Brazil (43.1% lower) and India (65.5% lower).
3. Although Asia had the highest absolute case count due to its large population, South America and North America had the highest case density (cases per million), indicating greater proportional impact.

## Tools Used
Python, Pandas, Matplotlib
